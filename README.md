# Эмулятор командной строки UNIX

## Общее описание

Эмулятор командной строки UNIX-подобной операционной системы.

Проект выполнен на языке Python.

Реализованы этапы 1–4 практической работы.

## Реализованные функции

### Stage 1 — REPL

- консольный интерфейс командной строки;
- приглашение к вводу с именем VFS;
- разбор команд и аргументов;
- поддержка аргументов в кавычках;
- команда `ls`;
- команда `cd`;
- команда `exit`;
- обработка неизвестных команд;
- обработка неправильных кавычек.

На первом этапе `ls` и `cd` являются заглушками и выводят полученные аргументы.

### Stage 2 — Конфигурация

- передача пути к VFS через командную строку;
- передача пути к стартовому скрипту;
- вывод параметров при запуске;
- выполнение стартового скрипта;
- поддержка комментариев в скрипте;
- вывод выполняемых команд;
- обработка отсутствующего стартового скрипта.

### Stage 3 — Виртуальная файловая система

- загрузка VFS из CSV-файла;
- поддержка директорий и файлов;
- поддержка вложенной структуры VFS;
- работа VFS в памяти;
- проверка различных вариантов VFS.

### Stage 4 — Команды файловой системы

Реализованы команды:

- `ls` — вывод содержимого текущей директории;
- `cd` — переход между директориями;
- `pwd` — вывод текущего пути;
- `uptime` — вывод времени работы эмулятора;
- `exit` — завершение работы.

Также реализована обработка ошибок:
- отсутствующая директория;
- попытка перейти в файл;
- неизвестная команда;
- неправильные кавычки.

## Командная строка

Запуск программы:

    python3 src/main.py <путь_к_VFS> <путь_к_скрипту>

Также доступен запуск через:

    ./run.sh

Пример:

    python3 src/main.py vfs_nested.csv script_stage4.txt

## Тестирование

Запуск тестов Stage 1:

    python3 -m unittest tests/test_stage1.py

Скрипты Stage 2:

    cd scripts
    ./test_stage2_1.sh
    ./test_stage2_2.sh
    ./test_stage2_3.sh

Скрипты Stage 3:

    ./test_stage3_minimal.sh
    ./test_stage3_files.sh
    ./test_stage3_nested.sh
