# Эмулятор командной строки UNIX

## Общее описание

Эмулятор командной строки UNIX-подобной операционной системы.

Проект выполнен на языке Python.

Реализованный этап: **Stage 1 — REPL**.

## Реализованные функции

На первом этапе реализованы:

- консольный интерфейс командной строки;
- приглашение к вводу с именем VFS;
- разбор команд и аргументов;
- поддержка аргументов в кавычках;
- команда `ls`;
- команда `cd`;
- команда `exit`;
- обработка неизвестных команд;
- обработка неправильных кавычек.

Команды `ls` и `cd` на данном этапе являются заглушками и выводят полученные аргументы.

## Поддерживаемые команды

| Команда | Описание |
|---------|----------|
| `ls` | Выводит имя команды и переданные аргументы |
| `cd` | Выводит имя команды и переданные аргументы |
| `exit` | Завершает работу эмулятора |

## Запуск

Для запуска программы используется:

    ./run.sh

Также программу можно запустить напрямую:

    python3 src/main.py

После запуска появляется приглашение:

    default>

Пример:

    default> ls file.txt
    ls ["file.txt"]

    default> cd "my folder"
    cd ["my folder"]

    default> exit

## Обработка ошибок

При вводе неизвестной команды выводится сообщение:

    Ошибка: неизвестная команда

При неправильных кавычках:

    Ошибка: неправильные кавычки

## Тестирование

Для запуска тестов используется:

    python3 -m unittest tests/test_stage1.py

Тесты проверяют:

- разбор простой команды;
- разбор аргумента в кавычках;
- разбор нескольких аргументов;
- обработку неправильных кавычек.

Пример успешного запуска:

    ....
    ----------------------------------------------------------------------
    Ran 4 tests in 0.000s

    OK
